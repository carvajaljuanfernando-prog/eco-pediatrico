# Cómo leer un informe de ecocardiograma pediátrico — manual interactivo

Página web autónoma (un solo `index.html`, sin dependencias de build) para enseñar a pediatras, médicos de urgencias, médicos generales y de UCI a interpretar un informe de ecocardiograma pediátrico.

**Autor:** Dr. Juan Fernando Carvajal Estupiñán — Cardiólogo, Instituto del Corazón de Bucaramanga.

## Contenido

14 capítulos: Z-score · anatomía del informe y análisis segmentario · cortocircuitos · ventrículo izquierdo · VD e hipertensión pulmonar · válvulas · coronarias · aorta y arco · pericardio · posoperatorios (Fallot, switch arterial, Fontan) · hallazgos críticos · caso resuelto · referencia rápida · autoevaluación (72 preguntas, tres niveles, sin repetición).

Herramientas interactivas: intérprete de Z-score (incluye clasificación coronaria AHA 2017), decodificador del análisis segmentario, test de burbujas, clasificador de hipertrofia del VI y validez de la FA, estimador de presión del VD y pulmonar, confiabilidad del gradiente valvular, Doppler de aorta abdominal, signos de taponamiento, control posoperatorio y hallazgos críticos.

## Publicar en GitHub Pages

1. Crea el repositorio `eco-pediatrico` en la cuenta `carvajaljuanfernando-prog`.
2. Sube `index.html`, `manifest.webmanifest` y este `README.md` a la raíz.
3. Settings → Pages → Deploy from a branch → `main` / `(root)`.
4. Quedará en `https://carvajaljuanfernando-prog.github.io/eco-pediatrico/`.
